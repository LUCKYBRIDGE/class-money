# 경쟁서비스 실측 지표 v4

## 1. 목적

공개 문서만으로 ‘UX가 더 좋다’를 단정하지 않는다.

Craft Anything Clean Room 또는 직접 정당한 계정으로 동일 시나리오를 수행하고 정량·정성 근거를 수집한다.

Craft Anything은 2026-11 현재 early alpha이며 공식 STATUS/ROADMAP상 Clean Room live build 검증이 아직 남아 있는 항목이 있으므로 자동 결과도 사람이 증거와 함께 검토한다.

## 2. 동일 테스트 데이터

모든 서비스:
- 교사 1
- 학생 25
- 모둠 5개
- 직업 5종
- 상점 6상품
- 주급
- 저축목표 1개
- 잘못 지급 1건

가능하지 않은 기능은 N/A.

## 3. 교사 효율

측정:
- 신규반 생성 단계
- 25명 roster 등록 시간
- 개인 지급 clicks/time
- 모둠 지급
- 전체 지급
- 오지급 정정
- 직업 생성/배정
- 10건 주문 승인
- 거래 export

## 4. 학생 인지

과제:
- 현재 사용가능액 찾기
- 최근 급여 이유 설명
- 구매 후 잔액 예측
- 저축목표 남은액 확인
- 거래 오류 이해

5명 이상 소규모 사용성 테스트에서 오류/질문 기록.

## 5. 거래 신뢰성

시나리오:
- 지급 버튼 더블클릭
- 페이지 새로고침
- 동시에 두 구매
- 주문 후 가격변경
- 자동급여 재실행
- 환불
- batch 일부실패

실제 서비스에서 공격적 테스트는 하지 않고, 우리 Class Money 구현에 강하게 적용.

## 6. 접근성/기기

뷰포트:
360
768
1280

확인:
- 가로스크롤
- 터치타깃
- 키보드
- focus
- 색 외 상태표현
- 숫자 가독성
- 공용기기 학생전환

## 7. 정보구조

최상위 메뉴 수
핵심 작업까지 depth
학생 화면의 비활성/미학습 메뉴 노출
teacher-only setting 분리
경제/게임 혼합 정도

## 8. 교육적 마찰

각 서비스에서:
- 자동화된 단계
- 학생이 직접 하는 단계
- 계산
- 선택
- 회고
를 기록.

좋고 나쁨이 아니라 ‘누구의 어떤 마찰인가’를 분류.

## 9. 공정성

관찰:
- 공개 leaderboard
- 벌금
- 기본소득
- 직업 없는 학생 처리
- 신용점수 공개
- 자산 공개
- 학생간 송금
- 실제 학교권리 상품화

## 10. 증거 등급

E0 추정
E1 공식문서
E2 실제 화면 재현
E3 반복 계측

UX 점수는 E2 이상에서만 부여.

## 11. 점수화

실제 비교가 가능할 때만:
교사효율 25
학생이해 20
거래신뢰 20
공정성/안전 15
접근성 10
확장성 10

결측이 크면 종합점수 금지.

## 12. Craft Anything 주의

공식 프로젝트는 Clean Room에서 내부 코드/페이지 소스를 읽지 않고 방문자가 볼 수 있는 화면, 텍스트, 측정 레이아웃, 메뉴 등을 이용한다고 설명한다.

2026-11-04 STATUS와 ROADMAP에는 Clean Room live build를 실제로 끝까지 확인해야 하는 항목이 남아 있다.

따라서:
- 스크린샷
- visible text
- measured layout
- 클릭 결과
를 증거로 저장하고
‘도구가 성공이라고 말했다’만으로 성공 판정하지 않는다.
