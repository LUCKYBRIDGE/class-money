# 검증 계획·증거 원장·평가표

## 1. 확인 기준
- E1: 공식 제품 문서·홈페이지 명시 — 기능 존재에 대한 출처, 실제 사용성의 증거는 아님.
- E2: 실제 접근 가능한 화면에서 재현한 관찰 + 스크린샷 + 날짜/뷰포트/로그.
- E3: 동일 과제를 여러 번 성공시킨 계측(클릭수/처리시간/오류 복구).
- E0: 불명·추정. 결과에는 항상 미확인으로 표기.
- 실행되지 않은 Craft Anything 테스트 결과는 기입하지 않음.

## 4. Craft Anything 실제 분석 계획
원 프로젝트: https://github.com/storytold/craft-anything
- 공식 README 기준 **Clean Room**은 사용자가 보는 화면·메뉴·측정 레이아웃을 대상으로 하고 원본 내부 코드·파일을 읽지 않음.
- 기능 조사에는 'Just look inside' / Advanced 작업흐름을 검토하되, 실제 명령·지원 상태는 설치된 버전에서 확인.
- 현재 프로젝트는 early alpha; 결과를 맹신하지 않고 캡처/로그/행동 재현으로 검증.
- 로그인 필요한 서비스는 정당하게 발급받은 실사용/체험 계정에서만 접근하고 개인정보가 있는 스크린샷은 저장하지 않음.
- `observations/<service>/YYYY-MM-DD-<scenario>.md`에 원본 링크·증거·판단·가설을 기록.
- 공급자별 약관·로봇 정책/사용 권한을 확인하고 유사 디자인·로고·코드 복사 금지.
