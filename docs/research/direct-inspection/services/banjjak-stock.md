## 직접 관찰에서 가장 중요한 제품교훈

1. 계정마찰을 QR로 제거.
2. 실제시장 UI의 몰입을 활용.
3. 환전을 자동화하지 않고 학습행동으로 남김.
4. 매매일지로 결과 중심 게임화를 보완.
5. 교사 Dashboard와 access window로 교실 통제를 유지.
6. 시장/시세 외부 의존성은 core 경제와 분리해야 함.
