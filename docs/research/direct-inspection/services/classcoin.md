## 공개 사이트에서 직접 확인한 정보구조
홈은 제품을 단순 경제앱보다 **학급 자동화 + 교실 경제**로 먼저 정의한다.

첫 진입:
- 교사: Kakao / Google
- 학생: 학급코드
- 별도 점수판 전용창

페이지 설명 순서:
1. Hero / 역할별 진입
2. 최근 업데이트
3. Kiosk 점수판
4. 학급경영
5. 금융경제
6. 즐길거리

즉 교사가 수업 중 매일 쓰는 surface를 먼저 보여주고 고급 경제기능을 뒤로 배치한다.

## 2026-10-26 업데이트에서 직접 드러난 UX 문제와 대응
- 학생 메뉴 왼쪽 펼침/스크롤
- 설정을 학급/활동/소통으로 재분류
- 실험실 메뉴/놀이카드 숨김
- 대시보드 학생 선택 개선
- 가계부 최근 3일 우선
- 누진세/세제혜택 저장 전 학생별 대상·금액 미리보기
- 팜코인과 학급화폐 분리
- 종료 전 보존/소멸 안내
- 실패한 직업지원 알림을 처리완료로 숨기지 않고 재조회

기능 확장 후 발생한 복잡도를 **숨김, 재분류, Preview, 재화분리, 실패상태 보존**으로 풀고 있다.

## 직접 관찰로 확인한 고위험 영역
- 실제 주식/금/가상화폐 연동
- 자리/사물함 소유권
- 행운상자
- 리더보드형 퀴즈
- 신용 차감

이 기능들은 Class Money에서 기본 경제와 분리하거나 제외 검토가 필요하다.

## 공개 GitHub 판정
GitHub에서 classcoin 이름의 여러 repository가 검색되지만 classcoin.me의 현재 공식 제품 source라는 근거는 확인하지 못했다.

따라서 내부 stack, DB, API를 추정하지 않는다.

## 현재 미확인
- 로그인 후 교사 Dashboard의 실제 최상위 메뉴 수
- 개인/모둠/전체 지급 click depth
- 학생 홈 first fold
- 직업 등록/배정/급여 실제 화면
- 상점 주문 상태
- 모바일 navigation
- accessibility

## Class Money에 가져올 것
- 수업용 Quick Surface와 경제관리 화면 분리
- 기능이 늘어날수록 비활성 모듈 완전 숨김
- 고위험 정책 저장 전 학생별 영향 Preview
- 게임 재화와 경제 재화 분리
- 실패 notification을 성공처럼 소거하지 않음
- recent-first ledger
