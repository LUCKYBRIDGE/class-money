## 판정 원칙
공식 organization에 있다는 사실만으로 현재 제품 source라고 보지 않는다.

다음이 모두 중요하다.
- repository description
- README의 목적
- 최근 activity
- 실제 product와의 연결
- source tree
- 공식 사이트/개발문서 연결

현재 제품 본체가 아니면 내부 architecture 근거로 사용하지 않는다.
