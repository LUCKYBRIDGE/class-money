# 교실경제 경쟁서비스 심층 분석 v2 — 2026-11-08

> **증거 범위**: 2026-11-08 기준 공식 공개 사이트·도움말. 로그인 뒤의 실제 화면, Craft Anything 실측, 실제 사용성 테스트는 실시하지 않았다. '확인된 제품 기능'과 '우리의 제안'을 섞지 않는다.

## 0. 질문부터 정의하기
목표는 기능 복제가 아니다. 한국 초등학교 교실에서 교사가 지속 가능한 경제 시스템을 운영하고 학생이 선택의 결과를 이해하게 만드는 것이다. 이 분석은 다음 질문을 검증한다.

- 교사가 일주일에 몇 번, 몇 번의 클릭으로 학급 경제를 유지할 수 있는가?
- 학생에게 보상이 지급되는 순간이 아니라 **벌고, 쓰고, 모으고, 계획하는** 전체 순환이 완성되는가?
- 직업을 얻지 못하거나 수학에 어려움이 있는 학생도 공정하게 참여하는가?
- 결제 중복·오입력·누락·급여 날짜 변경을 처리할 수 있는가?
- 경제 활동을 교육과 연결하면서 사행성·경쟁·개인정보 침해를 방지하는가?

### 서비스별 분석 — 사실 / 시사점 / 비도입
#### 클래스코인
공식 홈페이지에서 확인: 학급 코드 학생 입장, 교사 카카오/Google 로그인, 점수판 터치 지급, 퀘스트, 학급 아이템 상점, 기부 온도계, 저축 상품과 자동이자·세금, 직업·자동급여, 자리/사물함 부동산, 국내 주식/금/가상화폐 연동 간접 투자, 행운상자·퀴즈·펫. 2026-10-26 공지에는 누진세·세제혜택, 국고 정기지출, 상점 꾸미기/후기, 실험 기능 등 다수 기능이 기재됨.
- 시사점: 직업/금융/상점/교실 활동을 단일 화폐 원장과 연결하고, 게임 기능은 기본 경제와 분리된 선택 모듈로 설계.
- 위험: 메뉴가 확장할수록 핵심 업무 탐색이 어려워질 수 있음(**분석 가설**이며 실제 조작 테스트 전 단정 금지); 투자시장 연동과 추첨 콘텐츠는 교육 목적·과몰입·공정성 검토 필요.
- 증거: https://classcoin.me/ (최근 업데이트 2026-10-26).

#### ClassBank
공식 가이드: 보상, 직업, 청구서, 상점 4개 요소가 선택형. 초기 설정 가이드는 반/학생/보상/상점을 먼저 만든 후 직업·청구서·저축·보조교사를 추가할 수 있다고 설명. 현재 가격표는 개인 교사 무료 플랜과 Pro 기능을 구분함.
- 시사점: '간단 시작'과 '상세 시작'을 분리하고 운영 단계가 올라갈수록 모듈 활성화. 가격/급여/고정비 추천을 하나의 진단 화면으로.
- 수치 비교: 공식 3~5학년 예시 주급 $25, 월 소득 $100, 월 고정비 $80, 자유 금액 $20. **이 숫자는 미국 서비스의 사례로만 기록**. 설계 비율 참고: 고정비/정기소득=80%, 잔여=20%, 무조건 채택 X.
- 위험: 숙제 면제, 자리 이동, 쉬는 시간 확대와 같은 보상을 그대로 도입하면 학습권·공정성 문제가 생길 수 있음.
- 확인: https://help.classbank.com/en/articles/6499914-classbank-suggested-settings ; https://help.classbank.com/en/articles/6499058-how-do-i-get-started-with-classbank ; https://www.classbank.com/pricing

#### Cashroom
공개 설명: 중학생을 대상으로 직업지원/급여, 월세·공과금, 상점·교사 주문승인/영수증, 목표저축/이자, 신용·대출을 제공. 학생은 거래를 기록하기 전에 거래 후 잔액을 계산하고 입력한다. 교사는 학생별 해당 계산 과정을 끌 수 있고, 정기급여·청구서 자동화, 요청함 통합, 지급 되돌리기와 거래내역 내보내기 기능을 설명함.
- 시사점: 학생 측 거래 상세를 '이전 잔액 → 변화액 → 예상 잔액 → 결과 확인'의 학습 활동으로 제공. 교사는 초등학생의 수준에 따라 계산 모드를 비활성화하거나 힌트를 제공.
- 위험: 학생의 계산 실수가 실제 돈 손실로 이어지지 않도록 정답 검증과 적절한 피드백, 자동 재시도 제한 필요. 신용점수 수치는 학급 내 낙인 위험이 있어 채택 보류.
- 확인: https://cashroomapp.com/

#### Banqer Primary
공개 제품 설명: Basic Income, Expenses, Careers/Employment, Banking, Interest on Savings, Term Deposits, Superannuation, Tax, Property, Insurance, Transport 등 개념이 모듈로 제공됨. 영상과 퀴즈/학급 그룹 활동으로 학습 보조.
- 시사점: 돈 관련 기능과 별개로 **왜 이 활동을 하는가?**에 대응하는 10분 활동 카드/질문/회고를 모듈마다 제공.
- 위험: 호주 퇴직연금·보험·주택담보대출 등은 한국 초등 상황과 거리가 있을 수 있으며 수업 교육과정의 목표에 맞춰 재구성해야 함.
- 확인: https://banqer.co/au/primary/how-it-works

#### ClassCents
공식 홈페이지: 화폐명/기호·정수 포인트 모드, CSV/Excel/붙여넣기 학생 등록, 직업/상품 예시, 개인/모둠/전체 보상 및 차감, 일·주·월 급여, 지급 되돌리기와 CSV 출력, 학생 이메일 없는 인쇄 로그인 카드, 학생 로그인 없이 교사 화면만으로 운영.
- 시사점: 초등학교 기기·계정 제약에 강한 **교사 단독 모드**를 기본 옵션으로 두고, 학생 계정은 점진적으로 제공.
- 주의: 사이트에는 학생 잔액이 여러 교실에 걸쳐 공유된다고 설명됨. 우리 제품은 **학급별 원장 기본 격리**를 권장하며 공유 화폐는 명시적 별도 기능으로 다룸.
- 확인: https://www.classcents.com/

#### My Classroom Economy
공식 4~5학년 페이지에서 매월 급여·벌금·책상 임대료·경매와 학년말 회고를 설명; 초기 직업 선정과 학생의 상위 희망 직업 신청을 권장.
- 시사점: 온라인 기능 못지않게 '학급 회의와 경제 규칙 정하기', '월말 통장정리/회고' 같은 운영 수업을 포함.
- 위험: 실제 필수 학교 공간을 자산/임대료로 취급하더라도 사용권 박탈 금지. 학습권과 화폐의 교환을 철저히 분리.
- 확인: https://myclassroomeconomy.org/en/grades4-5

#### Greenlight
공식 도움말: 개별 과업 보수를 계좌/저축/기부 등 범주에 비율 혹은 고정 금액으로 나누며 합계 100%를 검사함.
- 시사점: '급여받기 전 20% 저축' 같은 선택형 자동 배분 UI, 소비·저축·공동체 기여 표시.
- 주의: 실제 금융 결제 기능 연동은 하지 않는다.
- 확인: https://help.greenlight.com/hc/en-us/articles/50527840580379-How-do-I-pay-my-child-per-chore-and-split-the-earnings

## 3. 평가 방법 — 사실 점수와 설계 점수 분리
기능 **존재 확인**(E=공식 출처 확인, U=미확인, N=명시적으로 미지원)과 **실제 조작 점수**(0~4, 미실측 N/A)를 절대 혼용하지 않는다.
- 1차 공개정보 문헌 검토에 기반한 서비스 종합 UX 점수는 **산출하지 않음**.
- 후속 실측 시 가중치 제안: 교사 효율 25%, 학생 개념 이해 20%, 거래 신뢰성 20%, 공정성/안전 15%, 접근성 10%, 확장성 10%.
- 결측치가 20% 이상이면 종합점수 비교 금지. '없음'과 '로그인 제한으로 관찰 불가' 구분.

## 4. 종합 결론
1. 가장 유용한 제품 구조 = **ClassBank의 단계형 설정 + ClassCents의 초경량 운영 + Cashroom의 학습 순간 + Banqer의 수업 시나리오 + 클래스코인의 통합 확장 구조**.
2. MVP의 경쟁력은 '가장 많은 기능'이 아니라 **25명 학급을 교사가 쉽게 관리하고 거래 오류를 수정할 수 있는 능력**.
3. 학생에게 가장 중요한 단위는 잔액이 아니라 **선택 과정과 그 결과의 설명**.
4. 모든 경쟁사에서 보이는 기능도 정당화되지 않으면 도입하지 않는다. 특히 벌금, 좌석·휴식·교육기회 상품화, 성적 기반 보상, 공개 부자 순위, 확률형 보상은 교육적 심사 필요.
