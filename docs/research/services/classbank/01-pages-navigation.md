# ClassBank — 페이지·내비게이션

## 제품/화면 지도

| 페이지·Surface | 직접 확인/구조적 역할 |
|---|---|
| 홈 | Award Bonuses / Assign Jobs / Charge Bills / Manage Store 네 행동을 먼저 제시. |
| Class Dashboard | 학급 단위 운영 진입점. |
| Students | 학생 등록·계좌·거래. |
| Setup / Bonuses·Fines | 행동/거래 사유 설정. |

## 페이지 구조를 볼 때의 핵심

- 이 표는 공개 홈·공식 도움말·공개 가이드에서 확인 가능한 **외부 IA**다.
- 로그인 후 실제 route 이름이나 URL 구조와 동일하다고 단정하지 않는다.
- 제품 본체 source가 공개된 경우에만 실제 route/file tree를 별도 기술문서에 기록한다.
