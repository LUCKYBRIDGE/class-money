# Banqer Primary 심층 분석

기준일: 2026-11-08  
분석 유형: Banqer 공식 Primary 기능 페이지·도움말 기반  
실측 상태: 실제 교사/학생 계정의 전체 동선은 미측정

## 1. 왜 분석하는가

Banqer Primary는 ‘교실에 화폐를 도입하는 앱’보다 ‘금융 개념을 경험하는 시뮬레이션 교육 플랫폼’에 가깝다. Class Money가 단순 학급 운영 도구를 넘어 실제 수업에서 경제교육을 담당하려면 가장 중요한 비교 대상 중 하나다.

## 2. 제품 정체성

Banqer Primary는 호주/뉴질랜드 초등 및 중간학년을 대상으로 실제 경제 개념을 단계적으로 경험하게 한다.

공식 기능 범위:
- Basic Income
- Expenses
- Careers and Employment
- Banking
- Interest on Savings
- Term Deposits
- Tax
- Property
- Insurance
- Transport
- 지역에 따라 Superannuation/KiwiSaver, Credit Reporting 등

핵심은 기능 하나하나가 독립된 ‘경제 개념’이라는 점이다.

## 3. 학습 구조

Banqer는 단순 거래 기능만 주지 않고:
- 영상
- 퀴즈
- 시뮬레이션 이벤트
- 그룹 활동
- 교사용 수업자료
를 경제 기능과 함께 제공한다.

따라서 학생이 ‘이자를 받았다’에서 끝나는 것이 아니라 이자가 무엇인지 배우고, 활동하고, 그 뒤 시뮬레이션에서 결과를 본다.

Class Money에 가장 중요한 시사점:
경제엔진과 수업자료를 분리하되 연결한다.

예:
저축 기능 → ‘저축이 왜 필요할까?’ 10분 활동 카드 → 목표 저축 실행 → 2주 후 결과 회고.

## 4. 경제 개념의 단계적 확장

Banqer 기능 순서는 학생의 경제 세계가 확장되는 순서로 볼 수 있다.

1. 소득
2. 지출
3. 직업
4. 은행
5. 저축·이자
6. 세금
7. 자산
8. 위험·보험
9. 교통/생활비
10. 더 복잡한 금융

이 순서가 Class Money에 중요한 이유는 메뉴 구조보다 ‘개념 성장 경로’를 설계할 수 있기 때문이다.

Class Money 권고:
기능 활성화 화면을 단순 토글 목록이 아니라 ‘학습 단계’로 보여준다.

## 5. Basic Income의 의미

Banqer는 Basic Income을 별도 개념으로 둔다. 이는 모든 경제참여가 직업성과에 달리지 않도록 하는 설계와 연결할 수 있다.

Class Money 적용:
- 기본 참여소득
- 직업 추가소득
- 과업 추가소득

세 종류를 분리.

이렇게 하면 ‘직업을 못 얻으면 경제활동에 참여할 수 없다’는 문제가 줄어든다.

## 6. Expenses

정기 지출을 통해 needs vs wants, 예산, 책임을 학습한다.

교육적 장점:
- 소비를 상점 보상만으로 제한하지 않음.
- 반복 지출이라는 실제 생활경제를 경험.

위험:
- 교실 자원이나 학습권을 실제로 박탈하는 구조가 되면 안 됨.
- 정기지출이 너무 크면 학생은 항상 적자이고 ‘좋은 행동 보너스’를 받아야만 생존하는 구조가 됨.

Class Money:
정기지출은 P2 선택형 시뮬레이션이며 기본 OFF.

## 7. Careers and Employment

학생이 CV 개념을 접하고 교실 직업에 지원하며 책임감을 경험한다.

좋은 점:
- 역할이 단순 당번이 아니라 경제적 계약/책임으로 보임.
- 학생의 선택과 지원 경험을 제공.

Class Money:
초등용으로 간단히:
‘내가 이 일을 하고 싶은 이유 / 잘할 수 있는 점’
두 문항 정도로 시작.

면접·CV는 학년별 선택 활동.

## 8. Banking

Banqer는 단순 지갑이 아니라 은행 계좌, overdraft, debt management 등의 결과까지 다룬다.

Class Money에서 가져올 핵심:
‘은행’ 메뉴를 장식처럼 만들지 말고 계좌의 역할 차이를 체험하게 한다.
- Spending
- Savings
- Treasury

초등 초기에는 checking/savings 정도만.

## 9. 이자와 정기예금

Interest on Savings와 Term Deposits를 분리한다.

학습적으로 좋은 점:
- 돈을 당장 쓰지 않는 대가와 보상을 경험.
- 유동성과 수익의 trade-off를 체험.

Class Money P2:
‘묶어두기’를 실제 금융상품처럼 복잡하게 만들기보다:
- 목표저축: 언제든 이동 가능
- 잠금저축: 2/4주간 사용 불가, 보너스 이자
정도로 단순화할 수 있다.

## 10. 세금

Banqer는 세율·구간·계산·공적 사용을 학습하게 한다.

Class Money는 세금을 단순 소각으로 처리하면 안 된다.

권고:
학생 지갑 → 학급 국고 → 공동체 사용처

학생은:
- 내가 낸 세금
- 학급 총 세수
- 어디에 사용되었는지
를 볼 수 있어야 한다.

## 11. Property·Insurance·Transport

이 모듈들은 Banqer의 ‘실제 인생 시뮬레이션’ 방향을 잘 보여주지만 Class Money 초등 MVP에는 적합하지 않다.

다만 설계 원리는 유용:
‘하나의 선택이 이후 비용 구조를 바꾼다.’

예:
교통수단을 산다 → 초기 지출은 크지만 주간 교통비가 줄어든다.

Class Money는 실제 부동산/자동차보다 초등 친화적 가상 시나리오로 재구성할 수 있다.

## 12. Class Store

Banqer Primary의 Class Store는 학생 대시보드에서 직접 장바구니→checkout→payment 흐름을 제공하고, 교사는 상점 개폐 및 교사 제작 상품의 claim 승인/거절을 관리한다.

흥미로운 점:
- 디지털 아바타 상품과 교사 상품을 함께 둘 수 있음.
- 상점을 교사가 열고 닫을 수 있음.
- 재고를 제한/무제한 설정.

주의:
도움말상 교사 상품 claim 거절이 곧바로 환불을 의미하지 않는 구조가 있어, Class Money는 사용자 기대에 맞게 상태와 환불 규칙을 더 명확히 해야 한다.

## 13. 게임화

Banqer dollars, avatars, store, quiz rewards, simulated events가 동기를 만든다.

장점:
- 장기간 참여.

위험:
- 금융개념보다 보상 최적화가 중심이 될 수 있음.
- 학습 퀴즈 점수가 경제자산으로 직접 이어지면 학업 성취와 경제적 우위가 결합할 수 있음.

Class Money:
학습 성취 보상은 소액/상한 또는 비금전 배지로 제한.

## 14. Class Money에 가져올 것

강하게 도입:
1. 경제 개념별 모듈
2. 기능별 수업카드
3. 기본소득
4. 정기지출의 선택형 시뮬레이션
5. 세금→국고→공공사용의 흐름
6. 선택에 따른 장기 결과
7. 교사 설정에 따른 단계적 개방

변형:
- Property → 가상 자산 시나리오
- Insurance → 위험 선택 카드
- Transport → 예산 trade-off 활동

초기 제외:
- 복잡한 overdraft
- 모기지
- 실제와 유사한 신용평점
- 퇴직연금 고급 구조

## 15. Craft Anything 후속 실측

- Expansion 활성화 방식
- 학생이 새 개념을 처음 접하는 화면
- 영상→퀴즈→시뮬레이션의 실제 순서
- 교사가 전체 반 진행상황을 보는 방식
- Class Store 구매/claim 처리
- 학생 대시보드의 정보 우선순위
- 경제 개념이 늘어날 때 메뉴 복잡도
- 학년별 설정 차이
- 태블릿 UI

## 16. 현재 판단

Banqer에서 Class Money가 가져와야 할 가장 큰 것은 ‘금융기능’이 아니라 ‘기능을 학습 단원처럼 설계하는 방식’이다.

Class Money의 차별화:
경제 기능 옆에 수업자료를 붙이는 것이 아니라, 경제 기능 자체가 수업 시나리오의 일부가 되도록 설계.

## 심화 보완: 12개 분석축

### A. 사용자와 권한
Banqer는 교사 대시보드, 학생 대시보드, 공동교사 구조를 갖고 학생별 progress와 거래정보를 교사가 볼 수 있다. 학생은 고유 username/password로 접근한다.

Class Money는 계정 접근뿐 아니라 학습모듈 공개권한도 권한 모델에 포함해야 한다.

### B. 모듈 상태
Banqer의 중요한 상태는 거래보다 학습모듈 자체다.

비활성 → 교사 preview → 활성 → 학생 학습 → quiz/activity 진행 → 완료

Class Money의 세금·저축·시장·대출도 이처럼 '기능 ON/OFF'가 아니라 '수업단계' 상태를 가져야 한다.

### C. 교사 JTBD
- 이번 달 어떤 금융개념을 열지 결정
- 학생 진행상황 확인
- 직업시장 운영
- 수입/비용 규칙 관리
- 학생의 실제 선택을 수업 대화로 연결

따라서 교사 홈에는 경제통계만큼 모듈 진도와 다음 수업 제안이 중요하다.

### D. 학생 JTBD
학생은 돈을 많이 모으는 것이 아니라:
- 새 개념을 이해
- 시뮬레이션에서 선택
- 결과를 경험
- 퀴즈/활동으로 확인
하는 반복을 한다.

Class Money도 기능마다 이 네 단계를 설계하면 금융교육 정체성이 강해진다.

### E. 직업시장
job type, pay frequency, positions, CV, application, direct assignment, unemployment filter, terminate all contracts가 별도 상태로 관리된다.

Class Money 데이터 모델은 직업과 학생을 단순 many-to-many로 연결하지 말고 assignment/contract 객체를 둬야 한다.

### F. 장기과정 설계
공식 운영 가이드는 여러 모듈을 한꺼번에 열지 말 것을 권한다. 이것은 cognitive load를 다루는 제품정책이다.

Class Money 설정에는:
- 권장 학습순서
- 현재 단계
- 다음 추천모듈
- 예상 소요시간
이 있으면 좋다.

### G. 대시보드
교사 대시보드에서 progress, recent activity, account/transactions를 함께 본다.

Class Money는 다음 세 층을 구분:
1. 운영이상: 미처리/실패
2. 경제상태: 유통량/잔액
3. 학습진도: 어떤 개념을 경험했는가

한 화면에서 섞더라도 의미를 색이나 탭으로 분리한다.

### H. Leaderboard
Banqer는 savings/net worth/achievement 등 순위를 제공하고 일부는 끌 수 있다. Class Money는 이것을 그대로 쓰지 않는 편이 낫다.

대안:
- 개인 성장그래프
- 공동목표
- 비금전 학습배지
- 목표 달성자 익명 수

경제적 자산은 공개경쟁에 적합한 데이터가 아니다.

### I. 기기 환경
사례연구에서 25명에 14대 Chromebook 같은 환경이 언급된다.

Class Money는 1:1 기기를 필수로 하지 않는다.
- 교사단독 모드
- 모둠 순환
- 빠른 학생전환
- 출력 가능한 명세서
가 필요하다.

### J. 국가·교육과정 현지화
Banqer는 지역별 retirement, property, insurance 등 개념이 다르다.

Class Money는 한국 초등에 맞춰:
- 경제생활
- 합리적 선택
- 금융문해력
- 공동체와 세금
을 우선하고 성인 금융상품을 과도하게 모사하지 않는다.

### K. 제품결정
Adopt:
- 모듈별 학습
- 단계적 공개
- 직업 계약상태
- 진행도 대시보드
- 개념→체험→회고

Adapt:
- expenses
- property
- insurance
- transport

Avoid by default:
- 자산 leaderboard
- 초등에 과한 성인금융 구조

### L. 남은 실측
- 모듈 활성화 UI
- 학생 첫 진입 순서
- quiz와 경제보상의 관계
- teacher preview
- progress status 계산방식
- student dashboard의 메뉴밀도
- leaderboard 기본 노출과 비활성화 경험
