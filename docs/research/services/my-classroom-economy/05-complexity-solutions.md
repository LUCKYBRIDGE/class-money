# My Classroom Economy — 얽힌 문제와 해결방식

## 복잡한 문제를 어떻게 풀었는가

| 얽힌 문제 | 서비스의 해결방식 | Class Money에 번역 |
|---|---|---|
| 디지털화하면 학습 과정이 사라짐 | 수기 ledger/계약/수표가 사고과정을 외재화 | 합계는 자동화하되 예상·확인·회고는 남김. |
| 하나의 대시보드가 모든 맥락을 지움 | 행위별 별도 문서 | Class Money도 작은 task-specific 화면과 printable 병행. |
| 필수비용이 안정적 소득보다 큼 | bonus 의존 | 기본경제에서는 필수비용≤안정적 소득. |
| 자리/학습권 상품화 | Desk rent/ownership | 가상 asset으로 대체. |
| 학생 감독역할의 권력문제 | Police/Banker 역할 | 실제 시스템 권한은 제한·감사. |

## 평가 기준

좋은 해결방식인지 판단할 때:
- 교사 클릭 수만 줄였는가, 아니면 오류복구도 쉬운가?
- 학생에게 필요한 사고까지 자동화해 없애지는 않았는가?
- 다수 학생에게 적용할 때 batch/exception을 처리할 수 있는가?
- 역할/권한/경제상태가 섞여 있지 않은가?
- 정상경로뿐 아니라 실패·취소·환불·정정도 정의돼 있는가?
- 기능이 증가해도 기본 사용자에게 복잡도가 전파되지 않는가?
