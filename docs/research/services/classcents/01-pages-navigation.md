# ClassCents — 페이지·내비게이션

## 제품/화면 지도

| 페이지·Surface | 직접 확인/구조적 역할 |
|---|---|
| 홈/Setup | Money→Jobs→Payday→Shop→Transactions 흐름. |
| Roster | CSV/Excel/paste. |
| Jobs | 직업과 pay. |
| Payday | daily/weekly/monthly 자동지급. |
| Give/Deduct | 개인/그룹/전체, Saved Reason. |
| Shop | Rewards/Stock/Redemption. |
| Transactions | History/Undo. |
| Savings/Goals | 저축과 named Goal. |
| Student Dashboard | Earn/Spend/Save. |
| Login Cards | 학생 credentials 출력. |
| Export/Statements | CSV/print. |

## 페이지 구조를 볼 때의 핵심

- 이 표는 공개 홈·공식 도움말·공개 가이드에서 확인 가능한 **외부 IA**다.
- 로그인 후 실제 route 이름이나 URL 구조와 동일하다고 단정하지 않는다.
- 제품 본체 source가 공개된 경우에만 실제 route/file tree를 별도 기술문서에 기록한다.
