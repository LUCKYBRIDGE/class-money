# ClassCoin — 기능 얽힘·UI·UX 심층 분석

기준일: 2026-11-08  
증거: 공식 홈페이지/가이드 확인 + 구조적 해석. 로그인 후 실제 클릭 수와 픽셀 배치는 미검증.

## 1. 복잡성의 본질
ClassCoin은 점수판·퀘스트·직업에서 화폐가 들어오고, 상점·은행·세금·국고·부동산·투자·창업·게임으로 흘러간다.

\`\`\`mermaid
flowchart LR

 J[직업/급여] --> W
 W --> S[상점]
 W --> B[은행/저축]
 W --> T[세금/국고]
 W --> R[부동산]
 W --> I[투자]
 W --> E[창업/거래]
 W --> G[게임/펫/팜]
 D[대시보드/가계부] --> W
\`\`\`

기능 하나를 추가하면 메뉴뿐 아니라 거래내역·자산·알림·권한·설정에도 영향을 준다.

## 2. 복잡함을 풀어낸 방식
- **기능군 분리:** 공식 가이드에서 점수판, 학생관리, 퀘스트, 루틴, 직업, 상점, 경제 시스템, 대시보드, 게임, 대출, 설정 등을 큰 단위로 나눈다.
- **역할별 가이드:** 교사용/학생용 가이드를 분리한다.
- **기능 숨김:** 2026-10-26 업데이트에서 실험실 메뉴·놀이 카드 숨김을 추가했다. 기능이 많아질수록 '정렬'뿐 아니라 '비노출'이 필요하다는 실제 사례다.
- **설정 재그룹화:** 설정을 학급/활동/소통으로 재정리했다.
- **영향 미리보기:** 누진세·세제혜택은 저장 전에 학생별 예상 대상과 금액을 보여준다.

## 4. 교사용 핵심 UX
### 빠른 지급
공식 설명의 점수판은 학생 이름을 터치해 즉시 지급하는 흐름이다. Class Money는 이를 별도 Quick Action으로 두고 전체 경제 메뉴를 열지 않아도 개인/모둠/전체 지급이 가능해야 한다.

### 복잡한 규칙
세율·급여·정기지출·이자처럼 영향이 큰 설정은:
입력 → 학생별/학급전체 예상결과 → 경고 → 적용 날짜 → 확정
순으로 만든다.

## 5. 학생 UX
학생에게 직업·상점·은행·투자·부동산·펫·게임을 모두 같은 무게로 보여주면 경제학습의 주경로가 약해진다.

학생 홈 우선순위:
1. 지금 쓸 수 있는 돈
2. 최근 거래
3. 다음 급여
4. 목표
5. 오늘 할 일
6. 추가 활동

## 6. 상태와 피드백
최근 업데이트에서 급여 지급일 달력, 은행의 원금/현금/이자 구분, 전환 시 보존·소멸 안내, 실패 알림 재조회 등 상태 표현 개선이 확인된다.

Class Money 원칙:
예정/대기/실행/실패/정정/환불/소멸을 명확한 상태명으로 보여준다.

## 8. 가져올 원칙
- 기능을 많이 만들어도 모두 노출하지 않는다.
- 저빈도 기능은 활성화 후 나타난다.
- 복잡한 경제규칙은 저장 전 결과 미리보기.
- 교사 홈과 학생 홈의 정보 우선순위를 분리.
- 경제화폐와 놀이재화 분리.
- 실패 상태를 숨기지 않는다.
