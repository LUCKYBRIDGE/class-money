# 토스 유스 — 기능·흐름·상태

## 핵심 기능

- Prepaid balance
- Transactions
- Spending analytics
- Goals/Pots
- Learning content
- Simulation
- Social transfer/message
- Guardian management
- Safety/Recovery

## 주요 상태/흐름

- Balance: available vs saved
- Goal: active/progress/complete
- Simulation: virtual domain separated from real money
- Safety: normal→lost/problem→recovery

## 기능 연결 원칙

Youth Card→Allowance Tracker→Goal Pot→학습/모의투자→사회기능→보호자/안전 순으로 아동 금융경험을 단순한 언어로 조직.

기능을 독립 체크리스트로 보지 않고 다음 질문으로 연결해서 본다.

1. 이 기능이 어떤 객체/상태를 만든다.
2. 그 상태가 다른 기능의 사용 가능 여부를 바꾸는가.
3. 자동화가 실행되면 사용자에게 무엇이 보이는가.
4. 실패하면 어느 화면에서 다시 처리하는가.
5. 정정 시 원래 기록과 연결 상태가 어떻게 유지되는가.
