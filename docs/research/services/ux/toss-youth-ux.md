# 토스 유스 — 한국 청소년 금융 정보계층·UI·UX 심층 분석

기준일: 2026-11-08  
증거 수준: 공식 Toss Teens 공개 페이지 중심. 실제 개인 계정 화면 전체 실측 전.

## 1. 왜 UI 참고가 중요한가
Class Money는 한국 초등학생이 사용할 가능성이 높다. 따라서 한국 청소년 금융서비스가 사용하는 문장 길이, 정보 우선순위, 목표/소비 표현을 참고할 가치가 있다.

## 2. 복잡성의 원천
유스 서비스에는 카드, 잔액, 충전, 소비내역, 용돈기입장, Goal Pot, 학습, 모의투자 등 서로 다른 금융경험이 있다.

## 3. 핵심 해법: 기능보다 목적을 제목으로
공개 페이지의 기능은:
- Allowance Tracker
- Goal Pot
- Money Study Café
- Mock Investing Challenge
처럼 ‘무엇을 하는 기능인지’가 바로 드러나는 명칭을 사용한다.

Class Money 역시:
거래원장 / 자산배분
같은 관리자 용어보다 학생에게는
내 돈 / 모으기 / 오늘 할 일 / 사용내역
처럼 목적형 언어를 사용해야 한다.

## 4. Allowance Tracker의 UX 원리
공식 설명은 단순 기록보다:
- 돈이 어디로 갔는지
- 많이 쓴 날
- 아낄 수 있는 부분
을 보여주는 회고 기능을 강조한다.

Class Money 거래내역:
날짜별 로그만 나열하지 않고
- 이번 주 들어온 돈
- 나간 돈
- 가장 큰 지출
- 저축 변화
를 요약.

## 5. Goal Pot
목표를 세우고 단계적으로 모으며 얼마나 가까워졌는지 보여준다.

Class Money 목표 카드:
목표 이미지/이름
현재 / 목표
진행률
남은 금액
현재 속도 기준 예상 기간

초등에서는 숫자보다 시각적 진행을 크게 둔다.

## 6. Money Study Café의 시사점
짧은 퀴즈로 경제용어를 배운다.

Class Money는 학습자료를 길게 읽게 하기보다 경제기능을 처음 켰을 때:
- 1분 개념
- 한 문제
- 바로 체험
의 짧은 학습 루프를 제공할 수 있다.

## 7. Mock Investing Challenge의 시사점
실제 돈을 쓰기 전에 가상으로 경험하게 한다.

Class Money에서도 고급 기능은 본 경제 원장과 분리된 Simulation Wallet을 사용할 수 있다.

이렇게 하면 투자 실험 결과가 실제 학급 구매력에 영향을 주지 않는다.

## 8. 한국 사용자 관점의 UI 원칙
- 큰 숫자 1개를 최우선
- 최근 변화
- 다음 행동
- 짧은 문구
- 목표 진행 시각화
- 전문 금융용어 최소화

Class Money 학생 화면은 교사용 장부 UI처럼 보이면 안 된다.

## 9. UX 위험
- 실제 금융앱처럼 너무 세련된 소비 UX를 만들면 ‘쓰기’가 학습보다 앞설 수 있음.
- 모의투자가 메인 콘텐츠가 되면 경제교육이 투자게임으로 축소될 수 있음.
- 친구 송금/사회적 기능은 교실 관계 갈등 가능.

## 10. Class Money 적용
- 한국어 목적형 메뉴명
- 사용가능액 우선
- 주간 소비 회고
- 목표 진행 시각화
- 1분 개념학습
- 고급 시뮬레이션 별도 지갑
- 학생간 자유송금 기본 제외

## 11. Craft Anything 실측 항목
- 모바일 첫 화면의 숫자/텍스트 위계
- Allowance Tracker 카드 구성
- Goal Pot 진행률 표현
- 기능 진입 깊이
- 모의투자와 실제 유스 잔액의 시각적 분리
- 초등학생이 이해하기 어려운 용어 여부
