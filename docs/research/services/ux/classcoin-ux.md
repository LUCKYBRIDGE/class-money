# ClassCoin — 복잡성·정보구조·UI·UX 심층 분석

기준일: 2026-11-08  
증거 수준: 공식 공개 홈페이지/가이드에서 확인 가능한 메뉴·기능·업데이트 중심. 로그인 후 실제 화면의 클릭수·레이아웃 정밀 측정은 후속 실측.

## 1. 복잡성의 원천
ClassCoin은 단일 경제앱이 아니라 학급경영, 수업, 경제교육, 게임을 한 공간에 둔다. 공개 가이드에는 점수판, 학생관리, 퀘스트, 루틴, 직업, 상점, 경제시스템, 온도계, 자리배치, 대시보드, 팜타이쿤, 펫, 마켓플레이스, 퀴즈, 브레인런, 미션보드, 감사카드, 대출, DM, 설정 등이 병렬로 존재한다.

복잡성의 핵심은 기능 수보다 서로 다른 목적의 기능이 같은 학급·학생·화폐에 얽힌다는 점이다.

## 2. 복잡성을 풀어낸 방식
- 설정을 학급·활동·소통 등 도메인으로 재분류.
- 실험실 메뉴·놀이 카드 등 필요 없는 영역을 숨길 수 있게 함.
- 교사용/학생용 가이드를 분리해 역할별 경험을 나눔.
- 자산조정·가계부 등 운영/감사 기능을 학생 활동과 분리.
- 최근 기록을 먼저 보여주고 기간 조회를 확장하는 방식으로 기본 정보량을 줄임.

## 3. 정보구조 해석
이 서비스에서 배워야 할 것은 많은 메뉴가 아니라 가시성 제어다.

Class Money 권고:
교사 핵심 탭은 오늘 할 일 / 학생 / 지급 / 직업 / 상점 / 거래 / 경제설정 정도로 제한하고, 세금·국고·시장·경매·창업 같은 고급 기능은 경제 실험실 아래에 넣는다.

학생 핵심 탭은 내 돈 / 오늘 할 일 / 직업 / 상점 / 목표 / 거래내역 정도로 제한한다.

## 4. UI 패턴
### 점수판형 빠른 지급
수업 중에는 금융 설정 화면보다 학생 이름/아바타를 바로 눌러 지급하는 흐름이 적합하다.

### 설정과 실행 분리
즉시 지급과 세금·급여·자산 정책은 같은 화면에 섞지 않는다.

### 최근 기록 우선
가계부는 최근 기록을 먼저 보여주고 필요할 때 기간을 넓힌다. Class Money 거래장부도 최근 7일/최근 20건을 기본으로 하고 필터를 확장하는 편이 좋다.

### 대상 식별 강화
자산 조정 시 현재 선택된 학생을 명확히 보여주는 패턴은 오지급 방지에 중요하다. Class Money의 고액 지급·정정 화면에서도 학생, 금액, 이유를 상단에 고정한다.

## 5. UX 위험
- 게임 기능이 경제 핵심보다 더 강한 동기가 될 수 있음.
- 교사가 필요한 기능을 찾는 탐색비용 증가.
- 게임재화와 경제화폐가 섞일 위험.
- 초보 교사에게 고급 경제기능이 과부하.
- 투자·부동산이 경제교육 전체처럼 보일 위험.

## 6. Class Money 번역
1. 처음에는 5~7개 핵심 탭만 노출.
2. 기능을 켜기 전에는 메뉴에서도 숨김.
3. Starter / Classroom Economy / Simulation 프리셋.
4. 게임 재화와 경제 화폐 분리.
5. 고급 기능은 경제 실험실로 격리.
6. 교사 홈은 통계보다 오늘 처리할 일을 우선.
7. 자산조정은 관리자 흐름에서만 접근.
8. 학생 화면은 개인 경제와 현재 과업만 노출.
