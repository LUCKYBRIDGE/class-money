# NatWest Rooster Money 심층 분석

기준일: 2026-11-08  
분석 목적: 용돈 루틴, 과업 유형, 가상 화폐→실제 금융으로의 단계적 경험을 참고

## 1. 왜 분석하는가

Rooster Money는 가정의 용돈 관리를 중심으로 한다. Class Money와 맥락은 다르지만 ‘정기 용돈’과 ‘추가로 버는 돈’을 어떻게 분리하는지, 어린 연령에서 실제 돈을 쓰기 전 어떻게 가상 돈으로 습관을 형성하는지가 중요하다.

## 2. 기본 구조

Tracker 가이드에서:
- 주간/격주/월간 allowance
- 자동 지급
- 필요할 때 Boost
- extra earner chores
를 제공.

또한 Tracker는 실제 돈을 입금하지 않는 virtual money 방식으로 사용할 수 있고, 별도 카드 상품으로 실제 돈 사용까지 확장된다.

Class Money에는 virtual tracker 방식만 필요하다.

## 3. Allowance와 Extra Earner의 분리

Chores 공식 가이드는:
- Allowance chore
- Extra earner
를 구분한다.

Allowance chore:
정기 용돈과 연결된 책임.

Extra earner:
추가 수행 시 별도 보상.

이 구분은 Class Money에 매우 유용하다.

교실:
- 기본 참여소득
- 직업 기본업무
- 추가 과업 보수
를 분리.

모든 작은 행동을 즉시 돈으로 바꾸지 않게 한다.

## 4. 완료하지 않았을 때 ‘0 또는 부분 지급’

Rooster Money는 allowance chore가 미완료일 때:
- allowance 지급
- 미지급
- 부분 지급
등 가족 정책에 따라 다르게 운영할 수 있는 구조를 설명한다.

Class Money의 직업급여도 단순 완료/미완료 이분법보다:
- 정상 지급
- 일부 지급
- 보류
- 면제
를 정책으로 둘 수 있다.

다만 결석·지원 필요 등 학생에게 불리하게 적용되지 않도록 교사 예외처리가 필요하다.

## 5. Stars: 실제 돈 전에 보상개념 연습

Rooster의 Stars는 어린 아이가 실제 돈에 앞서 earning/saving/spending을 경험하는 가상 보상이다.

Class Money 시사점:
1~2학년에서는 실제 화폐 단위를 정교하게 흉내 내기보다:
- 별
- 토큰
- 간단 정수 화폐
로 시작할 수 있다.

고학년으로 갈수록:
- 지출
- 저축
- 예산
- 세금
을 확장.

## 6. 연령에 맞는 과업

Rooster Money는 연령별 chores 사례를 제공한다.

Class Money에서도 직업/과업 라이브러리를 학년별로 다르게 제안하는 것이 좋다.

예:
1~2학년:
- 정리
- 배부
- 화분 돌봄

5~6학년:
- 물품 관리
- 행사 운영
- 학급 통계
- 작은 프로젝트 관리

중요:
특정 성별/능력에 역할을 고정하지 않는다.

## 7. 용돈 ‘루틴’의 중요성

Rooster의 강점은 화려한 금융기능보다 반복되는 생활 루틴이다.

정기 지급일이 예측 가능하면 학생은:
- 언제 돈이 들어올지 알고
- 현재 돈을 얼마나 남겨야 할지 판단
- 목표까지 기간을 계획
할 수 있다.

Class Money:
다음 급여일을 학생 홈에 명확히 표시.

## 8. Pocket Money Index에서 얻을 수 있는 관점

Rooster는 실제 사용자 데이터를 바탕으로 용돈·과업·저축목표의 패턴을 정기적으로 공개한다.

Class Money가 배울 점:
교사에게 단순 학생별 잔액이 아니라 익명화된 학급 패턴을 제공.

예:
- 평균 저축률
- 가장 많이 선택한 목표 유형
- 직업 참여율
- 급여 대비 소비 비율

그러나 학생 간 순위는 제공하지 않음.

## 9. Class Money에 가져올 것

강하게:
1. 기본수입과 추가소득 분리
2. 정기 지급 루틴
3. 완료조건에 따른 부분 지급 정책
4. 연령별 직업/과업 추천
5. 저학년 단순 경제모드
6. 학생에게 다음 지급일 예고

변형:
- Stars → 저학년 간단화 모드
- Boost → 교사 특별 지급

제외:
- 실제 카드/실제 돈
- 가족 생활 데이터

## 10. Craft Anything 후속 실측

## 11. 현재 판단

Rooster Money는 ‘교실경제의 금융 기능’보다 ‘돈이 반복되는 생활 루틴 속에 자리잡는 방식’을 보여준다.

Class Money의 경제는 이벤트가 아니라:
월요일 할 일 → 금요일 급여 → 상점/저축 → 주말 회고
같은 반복 리듬으로 설계하는 것이 적절하다.

## 심화 보완: 12개 분석축

### A. 사용자와 권한
Rooster Money는 보호자가 allowance와 chore 규칙을 만들고 아이가 수행상태를 확인하는 가정경제 구조다.

Class Money에서는 보호자 대신 교사가 규칙을 갖지만, 교사의 생활통제 도구로 바뀌지 않도록 경제보상 가능한 과업의 범위를 좁혀야 한다.

### B. 과업 유형
Allowance chores와 Extra earners 구분은 매우 좋은 도메인 모델이다.

Class Money 대응:
- responsibility: 보상 없음 또는 기본역할에 포함
- job duty: 정기급여
- quest: 추가보상
- volunteer/community: 비금전 인정 가능

### C. 지급 정책
미완료 시 전액, 비례, 수동결정 등 정책이 가능하다.

Class Money는 직업마다:
- fixed
- completion-based
- teacher-reviewed
정책을 선택하게 할 수 있다.

### D. 공정성
학생마다 맡은 일의 난도와 수행기회가 다르다.

자동 비례급여를 켤 경우:
- 수행기준 명확성
- 결석 처리
- 특수한 지원 필요
- 역할 자체의 기회차이
를 고려해야 한다.

따라서 급여삭감은 기본 기능이 아니라 명시적 설정이어야 한다.

### E. 반복주기
용돈 시스템의 핵심은 주기성이다.

Class Money는 달력에서:
- 이번 지급기간
- 다음 Payday
- 미완료 조건
을 명확히 보여줘야 한다.

### F. Extra earning의 희소성
추가 일감이 일부 학생에게만 집중되면 격차가 커진다.

Class Money Quest:
- 개인별 주간 수락한도
- 선착순/모두/지정 유형
- 최근 참여 적은 학생 우선 옵션
을 검토할 수 있다.

### G. 보상 없는 활동
모든 classroom duty에 돈을 붙이지 않는 것이 중요하다.

경제앱이 공동체 윤리를 잠식하지 않도록:
'당연히 해야 할 일'과 '추가 경제활동'을 분리하는 교육 가이드가 필요하다.

### H. 저학년 단순화
가정용 앱의 star/단순 활동 경험은 저학년 경제입문의 참고가 된다.

Class Money 저학년 모드:
- 정수 화폐
- 큰 아이콘
- 저축/소비 두 가지
- 복잡한 세금/이자 숨김

### I. 데이터모델
Task와 Payment rule을 분리한다.
한 과업이 돈 없는 책임일 수도, 정기급여 조건일 수도, 별도 보상일 수도 있기 때문이다.

### J. 실패모드
- 완료 체크 누락
- 결석 학생 자동 미지급
- 같은 chore 중복 승인
- 지급기간 경계에서 중복
- extra earner 선착순 충돌

### K. 제품결정
Adopt:
- 기본책임/추가소득 구분
- 지급정책 선택
- 반복주기
- due date

Adapt:
- partial pay

Avoid:
- 일상의 모든 행동을 가격화

### L. 남은 실측
- chore 유형 전환
- incomplete allowance 처리
- approval
- recurring chore
- child view의 남은 일정
- 저학년 사용성

## V4 심층 해부 — 공동체 책임을 돈으로 오염시키지 않는 법

### 1. Allowance chores와 Extra earners의 구분이 교육적으로 중요하다

Rooster는 정기용돈과 연결된 책임과 별도의 추가수입 과업을 구분한다.

교실에서도 모든 행동을 돈으로 가격화하면:
- 규칙을 지키는 이유가 돈이 됨
- 친구를 돕는 행동도 보상 없이는 안 하게 됨
- 교사가 매 행동을 평가해야 함

따라서 Class Money 활동은 최소 네 유형으로 구분할 가치가 있다.

1. 공동체 기본책임: 금전보상 없음
2. 정기직업: 정기급여
3. 추가과업: 건별보상
4. 봉사/기여: 비금전 인정 또는 공동체기금

### 2. 부분 급여는 공정해 보이지만 분쟁이 많을 수 있다

Rooster는 과업 완료비율에 따라 allowance를 일부 지급할 수 있다.

교실에서 이를 기계적으로 적용하면:
- 결석
- 업무량 차이
- 친구의 방해
- 교사의 확인누락
같은 요소가 급여를 흔든다.

Class Money는 percentage pay를 고급설정으로 두고 기본은:
- 수행기준 충족 시 전액
- 미충족 시 교사 검토
가 안전하다.

### 3. Overdue와 Skip은 교실에서도 중요하다

공식 chores 구조에는 Overdue와 Skip이 있다.

Class Money 과업에서도:
- overdue
- skipped with reason
- excused
를 구분해야 한다.

결석학생을 단순 미완료로 처리하면 안 된다.

### 4. 추가과업의 기회 공정성

Extra earner가 인기 학생이나 빠른 학생에게 집중되면 경제격차가 커진다.

Quest 분배 정책 후보:
- 모두 가능
- 선착순
- 추첨
- 최근 참여 적은 학생 우선
- 교사 지정

선착순은 가장 간단하지만 가장 공정한 방식은 아니다.

### 5. 최종 판단

Rooster의 가장 중요한 교훈은:
‘무엇을 돈으로 보상할지’ 자체가 경제교육 설계라는 점이다.

Class Money는 화폐기능보다 먼저 활동의 의미를 분류해야 한다.
