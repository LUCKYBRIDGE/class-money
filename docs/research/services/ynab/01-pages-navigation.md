# YNAB — 페이지·내비게이션

## 제품/화면 지도

| 페이지·Surface | 직접 확인/구조적 역할 |
|---|---|
| Home | recent activity, upcoming, overview. |
| Plan | Category에 돈 배정. |
| Accounts | 실제 cash 위치. |
| Categories | 목적별 예산. |
| Targets | 금액/날짜 목표. |
| Auto-Assign | 자동배분 Preview. |
| Transactions | Account/Payee/Category/Memo/Amount. |
| Scheduled Transactions | 미래 거래. |
| Reconcile | 실제기록 대조. |

## 페이지 구조를 볼 때의 핵심

- 이 표는 공개 홈·공식 도움말·공개 가이드에서 확인 가능한 **외부 IA**다.
- 로그인 후 실제 route 이름이나 URL 구조와 동일하다고 단정하지 않는다.
- 제품 본체 source가 공개된 경우에만 실제 route/file tree를 별도 기술문서에 기록한다.

## Class Money 관점

- **Home**: recent activity, upcoming, overview.
- **Plan**: Category에 돈 배정.
- **Accounts**: 실제 cash 위치.
- **Categories**: 목적별 예산.
- **Targets**: 금액/날짜 목표.
