# 반짝 모의투자 — UI·UX·버튼/컨트롤

기준일: 2026-11-11

## 1. Landing UI

### 상단 Navigation
- 왜 반짝인가요?
- 수업 진행
- 주요 기능
- 자주 묻는 질문
- 지금 시작하기

한 페이지에서:
가치 → 사용법 → 학생/교사 기능 → 교육효과 → FAQ → CTA
순으로 내려가는 long-form landing 구조다.

### CTA
- 선생님으로 시작하기
- 학생 거래소 입장
- 지금 시작하기
- 1분 만에 알아보기

Primary CTA를 ‘서비스 둘러보기’가 아니라 실제 수업 시작 경로에 연결한다.

## 2. 역할 선택 UI

`index.php`는 거의 두 개의 큰 선택만 남긴다.

- 👩‍🏫 선생님 로그인
- 👦 학생 거래소 입장

복잡한 주식기능을 보기 전에 **사용자 역할 선택을 완료**한다.

## 3. 학생 주요 Tab

현재 소개 페이지에서:
- 🏆 랭킹
- 📈 거래소
- 💰 내 계좌
- 📝 매매일지
- 💱 환전

을 직접 시각화한다.

### 평가
기능 수가 늘었음에도 5개 정도의 행동 중심 탭으로 압축한다는 점은 좋다.

다만:
- 랭킹이 첫 번째에 배치되는 경우 경쟁/수익률 중심으로 학습목표가 오인될 수 있다.
- 교육 목적이라면 내 계좌/매매일지/거래소를 더 우선할 여지가 있다.

## 4. 거래 UI

2026-04-06 실제 학생화면 screenshot에서 확인된 매수 modal:

- 종목명 + 매수
- 닫기 X
- 일봉 캔들차트
- 호가창
- 현재가 강조
- 수량 -
- 수량 숫자
- 수량 +

### 장점
실제 증권앱과 유사한 mental model을 사용해:
- 차트
- 호가
- 수량
- 매수/매도
개념을 경험으로 익히게 한다.

### 주의
실제 증권사 UI를 닮는 것은 몰입에 좋지만 초등학생에게:
- 호가창 숫자 과밀
- 단기 가격변동 집중
- “많이 거래하는 것이 투자”라는 오해
를 만들 수 있다.

Class Money의 투자 Simulation에는 **간소화 모드 / 학습 모드**가 더 적합할 수 있다.

## 5. 환전 UX

현재 페이지는 학생이:
- 기준 환율
- 달러 살 때 시세
- 달러 팔 때 시세
- 보유 원화
- 보유 달러

를 보고 직접 환전한다고 설명한다.

### 좋은 점
미국주식 기능을 단순히 USD 가격으로만 보여주지 않고 **통화 변환 자체를 학습행동**으로 남긴다.

### 필요한 UX
실제 구현을 벤치마킹한다면 거래 전:
- 현재 보유 KRW
- 환전할 KRW/USD
- 적용환율
- 환전 후 KRW
- 환전 후 USD

를 명확히 보여주는 Before/After 구조가 중요하다.

## 6. QR/학생 관리 UI — 개발기에서 직접 확인

2026-04-06 개발기에서 교사 학생관리 행에 다음 네 버튼을 두도록 설계했다.

- 🚀 입장
- 📱 QR/인쇄
- ✏️ 수정
- 🗑️ 삭제

한 학생을 관리하기 위해 여러 페이지로 이동하지 않고 **row-level action**으로 모은 것이 특징이다.

## 7. 교사 Dashboard UX

현재 소개:
- 학생 계좌
- 종목
- 초기 자금
- 접속 가능 시간
- 수익률 현황

홍보자료:
- 실시간 포트폴리오 관제
- 수익률 자동 통계
- 학생/종목별 분석

### 해결하는 문제
학생 20~30명의 화면을 하나씩 열 필요 없이 학급 전체를 **aggregate view**로 본다.

## 8. 거래 이유 기록 UX

이 서비스에서 단순 모의주식 앱과 다른 핵심.

거래할 때/후에:
- 왜 이 종목을 골랐는가?
- 어떤 정보를 참고했는가?
- 다시 한다면 무엇을 바꿀 것인가?

를 매매일지에 연결한다.

### Class Money에서 가져올 가치
고급 경제활동에서는 단순 결과보다:
**선택 → 이유 → 결과 → 회고**
를 하나의 interaction으로 묶는 것이 좋다.

## 9. 수업시간 제어

FAQ에서 교사가 학생의 **거래소 접속 가능 시간대**를 설정할 수 있다고 명시한다.

이는 학교 서비스에서 중요한 UI 패턴이다.

- 기능이 존재하는가
- 학생이 지금 접근할 수 있는가

를 분리한다.

## 10. 개선 여지

### 랭킹
현재 핵심 학생탭/홍보에서 랭킹이 강조된다.
교육적으로는:
- 기본 OFF
- 개인 순위 대신 구간/전략 비교
- 수익률뿐 아니라 변동성·분산·일지작성 등 다양한 지표
가 더 안전하다.

### 시세 freshness
초기 자료의 1초/10초 표현이 불일치한다.
학생 화면에는 “실시간”만 쓰기보다:
- 마지막 업데이트 시각
- 지연 가능성
을 명시하는 편이 정확하다.

### 실제 시장시간
국장/미장은 시장시간과 시차가 다르다.
수업시간에 시장이 닫혀 있을 때:
- 마지막 가격
- 모의 장중
- 예약/체험모드
를 어떻게 설명하는지가 중요하다.
현재 공개 페이지에서는 상세정책이 확인되지 않았다.
