## 4. 학생 IA — 현재 소개 페이지에서 확인

현재 학생 화면의 주요 메뉴를 다음과 같이 직접 제시한다.

```text
학생 거래 경험
├─ 🏆 랭킹
├─ 📈 거래소
├─ 💰 내 계좌
├─ 📝 매매일지
└─ 💱 환전
```

### 학생 핵심 화면

#### 거래소
- 국장 / 미장 전환
- 종목명 또는 코드 검색
- 종목 탐색
- 매수/매도

#### 내 계좌 / 포트폴리오
- 보유 현금
- 보유 원화
- 보유 달러
- 종목별 보유 수량
- 평균 매입가
- 수익률

#### 환전
- 기준환율
- 달러 살 때 / 팔 때 시세
- 원화 → 달러
- 달러 → 원화

#### 매매일지
- 거래 판단 근거 기록
- 거래 후 회고
- 결과보다 판단과정을 수업 소재로 사용

#### 랭킹
- 우리 반 수익률 비교

## 6. 교사 IA — 현재 소개 페이지에서 확인

현재 소개 페이지는 교사 Dashboard가 다음을 관리한다고 설명한다.

```text
교사 Dashboard
├─ 학생 계좌
├─ 거래 가능 종목
├─ 초기 자금
├─ 학생 접속 가능 시간
└─ 수익률 현황
```

홍보자료에서는 추가로:
- 학생별 투자현황
- 종목별 투자분포
- 학급 수익률
- 개별 종목 분석
같은 통계를 Dashboard의 가치로 제시한다.

## 7. 수업 흐름 IA

현재 페이지는 제품 흐름을 다음 네 단계로 압축한다.

```text
STEP 1 우리 반 만들기
→ STEP 2 학생별 코드/QR 배포
→ STEP 3 환전하고 거래하기
→ STEP 4 수익률·매매일지 함께 보기
```

또 45분 수업 흐름을:
- 0~5분: QR 로그인
- 5~35분: 실시간 모의투자
- 35~45분: 교사 Dashboard 기반 분석·토론

으로 제안한 홍보자료가 공개돼 있다.

## 8. 페이지 설계에서 배울 점

### 역할을 가장 먼저 분리
복잡한 금융기능보다 Teacher / Student를 첫 화면에서 먼저 선택하게 한다.

### 학생 Navigation은 경제 행동 중심
“설정/데이터/상품” 같은 시스템 용어가 아니라:
거래소 / 계좌 / 일지 / 환전
으로 구성한다.

### 교사 화면은 관리기능보다 수업 통제 중심
초기자금·접속시간·수익률을 한 Dashboard에서 본다는 점이 교실용 서비스에 적합하다.
