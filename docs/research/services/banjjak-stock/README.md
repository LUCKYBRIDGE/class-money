# 반짝 모의투자 — Canonical Service Folder

기준일: 2026-11-11

> 대상: https://sub-teacher.com/API/stock/ad.html  
> 이 폴더를 **반짝 모의투자 분석의 최신 정본(canonical)**으로 사용한다.

**성격:** 초등·교실용 실시간 시장연동 모의투자 웹앱  
**증거 수준:** C+ — 현재 공개 서비스 화면 직접 관찰 + 공개 개발기록에서 일부 파일명/초기 설계 확인. 제품 전체 source는 비공개.

## 한 문장 구조

교사가 반과 학생·초기자금·거래 가능 시간을 설정하고, 학생은 별도 회원가입 없이 코드/QR로 입장하여 **국내·미국 주식 탐색 → 원화/달러 환전 → 매수·매도 → 포트폴리오 확인 → 매매 이유 기록 → 학급 단위 성찰**까지 수행하는 교실용 모의투자 웹앱이다.

## 가장 중요한 관찰

- 현재 소개 페이지는 **국장·미장·환전·포트폴리오·매매일지**를 하나의 학생 투자 경험으로 묶는다.
- 학생 회원가입을 없애고 **학생별 접속 코드/QR**로 진입 마찰을 줄인다.
- 교사는 학생 계좌, 종목, 초기자금, 접속 가능 시간, 수익률을 Dashboard에서 관리한다고 설명한다.
- 학생 화면은 랭킹 / 거래소 / 내 계좌 / 매매일지 / 환전을 주요 IA로 제시한다.
- 매매일지를 통해 단순 수익률 게임이 아니라 **판단 근거와 사후 성찰**을 붙이려 한다.
- 현재 공개 marketing은 “국장·미장 시세 기반”이라고 설명하지만 정확한 현재 시세 공급자·갱신주기는 공개 페이지에서 확인되지 않는다.
- 2026-04-06 개발기에는 “네이버 증권과 10초 단위 연동”이라고 적혀 있고 같은 시기의 홍보 이미지에는 “1초 단위” 표현이 있어, **시세 freshness는 별도 검증이 필요한 영역**이다.

## Class Money와의 관계

Class Money의 기본 경제엔진을 그대로 주식시장으로 만들기보다는, 이 서비스의 장점을 **선택형 ‘시장/투자 Simulation Lab’** 설계에 참고하는 편이 적합하다.

특히 참고할 부분:
- 짧은 학생 로그인
- 교사 수업시간 통제
- KRW/USD 등 통화 분리
- 거래 이유 기록
- 교사 관찰 Dashboard
- 실제 시장 느낌과 교육적 성찰을 연결하는 구조

그대로 가져오지 않을 부분:
- 공개 수익률 경쟁을 기본값으로 사용
- 실제 시세 수익률이 학생 경제자산 전체를 좌우하게 함
- 단기 매매 중심 UI만으로 투자교육을 대체
