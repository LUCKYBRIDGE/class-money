# ClassDojo — 페이지·내비게이션

## 제품/화면 지도

| 페이지·Surface | 직접 확인/구조적 역할 |
|---|---|
| Points | 학생 타일과 Skill 지급. |
| Groups | 학생 묶음 생성·선택. |
| Skills | custom feedback reason/value. |
| Reports | 상세 이력·기간·skill. |
| Redeem/Reset | 현재 표시값과 history의 다른 처리. |
| Display/Visibility | 학생·가족·공개 범위. |

## 페이지 구조를 볼 때의 핵심

- 이 표는 공개 홈·공식 도움말·공개 가이드에서 확인 가능한 **외부 IA**다.
- 로그인 후 실제 route 이름이나 URL 구조와 동일하다고 단정하지 않는다.
- 제품 본체 source가 공개된 경우에만 실제 route/file tree를 별도 기술문서에 기록한다.

## Class Money 관점

- **Points**: 학생 타일과 Skill 지급.
- **Groups**: 학생 묶음 생성·선택.
- **Skills**: custom feedback reason/value.
- **Reports**: 상세 이력·기간·skill.
- **Redeem/Reset**: 현재 표시값과 history의 다른 처리.
