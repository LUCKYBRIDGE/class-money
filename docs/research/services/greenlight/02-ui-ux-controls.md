# Greenlight — UI·UX·버튼/컨트롤

## 확인된 주요 컨트롤

| 버튼·컨트롤·행동 | 역할 |
|---|---|
| Set up allowance | 정기수입 wizard |
| Pay per chore | 과업별 보수 |
| Allocation % / amount | 수입 목적 배분 |
| Save | 100%/호환성 validation 후 저장 |
| Goal transfer request | 목표 인출 승인 |
| Permission toggle | 행동별 자율성 |
| Admin PIN | 공유화면에서 수정 보호 |

## UI·UX 관찰 포인트

- Primary action이 어느 사용자 역할에 속하는지 구분한다.
- 버튼 이름 자체보다 **행동 전 조건 → 클릭 → 처리중 → 성공/실패 → 복구**를 본다.
- Disabled 상태가 있다면 가능한 한 이유를 사용자에게 설명하는지 본다.
- 대량작업은 대상 수·총액·영향범위를 확정 전에 보여주는지 본다.
- 수업 중 고빈도 작업과 저빈도 설정 작업의 UI 밀도를 다르게 본다.
