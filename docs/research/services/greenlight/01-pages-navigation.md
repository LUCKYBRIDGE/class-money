| Parent Dashboard | Allowance·Permissions·Goals 관리. |

## 페이지 구조를 볼 때의 핵심

- 이 표는 공개 홈·공식 도움말·공개 가이드에서 확인 가능한 **외부 IA**다.
- 로그인 후 실제 route 이름이나 URL 구조와 동일하다고 단정하지 않는다.
- 제품 본체 source가 공개된 경우에만 실제 route/file tree를 별도 기술문서에 기록한다.
