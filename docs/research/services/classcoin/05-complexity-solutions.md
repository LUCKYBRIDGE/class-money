# ClassCoin — 얽힌 문제와 해결방식

## 복잡한 문제를 어떻게 풀었는가

| 얽힌 문제 | 서비스의 해결방식 | Class Money에 번역 |
|---|---|---|
| 기능 폭증 | 설정 재그룹화 + 저빈도 기능 숨김 | Class Money도 활성화 전 고급 모듈을 완전 숨김. |
| 복잡한 세금 규칙 | 학생별 영향 미리보기 | 급여·세금·이자·정기비용 모두 Preview 표준화. |
| 게임과 경제의 의미 혼합 | 팜코인/학급화폐 분리 가능 | 경제화폐와 놀이재화 분리. |
| 실패 상태가 사라지는 문제 | 실패 알림 재조회 | 실패를 완료로 덮지 않고 FAILED + Retry 유지. |
| 메뉴 탐색비용 | 최근 학생선택/왼쪽 메뉴 개선 | 사용빈도 중심 Teacher Home과 Quick Action 필요. |

## 평가 기준

좋은 해결방식인지 판단할 때:
- 교사 클릭 수만 줄였는가, 아니면 오류복구도 쉬운가?
- 학생에게 필요한 사고까지 자동화해 없애지는 않았는가?
- 다수 학생에게 적용할 때 batch/exception을 처리할 수 있는가?
- 역할/권한/경제상태가 섞여 있지 않은가?
- 정상경로뿐 아니라 실패·취소·환불·정정도 정의돼 있는가?
- 기능이 증가해도 기본 사용자에게 복잡도가 전파되지 않는가?
