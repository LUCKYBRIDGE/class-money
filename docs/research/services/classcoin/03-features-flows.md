# ClassCoin — 기능·흐름·상태

## 핵심 기능

- 점수판/보상
- 퀘스트·루틴
- 직업·자동급여
- 상점
- 저축·이자
- 세금·국고·정기지출
- 부동산·투자·창업·시장
- 대출/신용
- 게임·퀴즈·별도 게임재화
- 알림·공지·쪽지

## 주요 상태/흐름

- 직업: 모집→지원→배정→근무→급여
- 정책: 작성→영향 미리보기→활성→실행
- 알림: 정상/실패/재조회
- 게임재화: 사용/전환/종료/보존·소멸 안내

## 기능 연결 원칙

매일 쓰는 학급운영 surface 위에 직업·급여·상점·저축·세금·국고·자산·게임을 계속 확장한 통합형 서비스.

기능을 독립 체크리스트로 보지 않고 다음 질문으로 연결해서 본다.

1. 이 기능이 어떤 객체/상태를 만든다.
2. 그 상태가 다른 기능의 사용 가능 여부를 바꾸는가.
3. 자동화가 실행되면 사용자에게 무엇이 보이는가.
4. 실패하면 어느 화면에서 다시 처리하는가.
5. 정정 시 원래 기록과 연결 상태가 어떻게 유지되는가.
