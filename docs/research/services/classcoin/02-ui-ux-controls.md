# ClassCoin — UI·UX·버튼/컨트롤

## 확인된 주요 컨트롤

| 버튼·컨트롤·행동 | 역할 |
|---|---|
| 교사 시작 | Kakao / Google |
| 학생 입장 | 학급코드 |
| 학생 타일/선택 | 빠른 지급의 시작점 |
| 기능 숨김 | 실험실 메뉴·놀이 카드 비노출 |
| 세금 정책 미리보기 | 저장 전 학생별 대상·금액 확인 |
| 기간 변경 | 가계부 기본 최근 3일에서 범위 변경 |
| 재조회 | 실패한 직업지원 알림을 처리완료로 숨기지 않고 복구 |

## UI·UX 관찰 포인트

- Primary action이 어느 사용자 역할에 속하는지 구분한다.
- 버튼 이름 자체보다 **행동 전 조건 → 클릭 → 처리중 → 성공/실패 → 복구**를 본다.
- Disabled 상태가 있다면 가능한 한 이유를 사용자에게 설명하는지 본다.
- 대량작업은 대상 수·총액·영향범위를 확정 전에 보여주는지 본다.
- 수업 중 고빈도 작업과 저빈도 설정 작업의 UI 밀도를 다르게 본다.

## 아직 실측이 필요한 것

- 로그인 후 실제 최상위 메뉴 수
- 지급 click depth
- 학생 홈 first fold
- 현재 frontend/backend/DB
