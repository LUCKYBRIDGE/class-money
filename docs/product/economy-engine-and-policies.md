# 교실경제 엔진·정책·경제 균형 설계 (결정 제안)

상태: 제품 설계안. 특정 경쟁사의 내부 동작을 재현한 명세가 아니다.

## A. 월간/주간 경제 주기
1. 학급 화폐 발행/초기 지급 (교사 통제, 내역 기록).
2. 직업 배정 → 활동 완료 확인(선택) → 지급 주기에 맞춰 급여.
3. 학생은 자유 예산을 소비/저축/공동체 기여로 나눔.
4. 상점 구매는 가격·재고·잔액 확인 → 승인 → 영수증.
5. 주말/월말 학급 경제 결산, 다음 기간 예산 계획과 회고.

### 권고하는 경제 용어
**가용 잔액**: 지금 사용할 수 있는 금액 / **저축 잔액**: 별도 목표에 넣은 금액 / **이번 달 수입·지출**: 해당 기간 실제 거래 흐름 / **예상 지급**: 예정일 뿐 원장 미반영. '부자' '가난' 등 개인 평가 용어 사용 금지.

## B. 경제 밸런스 산식
기호: B=기간 기본소득, J=평균 직업소득, V=예상 선택 보상, F=선택 고정지출, P=대표 상품 가격, S=저축 목표액.

- 기본 정기소득 I=B+J (선택 보상 V는 생계 유지를 위한 필수 재원으로 가정하지 않음).
- 안정 여유액 D=I-F. **D<0 경고**, D=0이면 선택·저축 불가 경고.
- 고정비 부담률 R=F/I (I=0이면 정의하지 않음).
- 예상 목표 소요기간 N=ceil(S/max(예상 기간별 저축액,1)), 단 저축액<=0이면 '달성 불가'로 표시.
- 상품 구매 가능 기간은 **저축 제외 가용 자금** 기준으로 별도 산출.
- 자산 격차는 수업용 교사 통계로만 요약, 공개 개인 순위는 기본 비활성화.

### 예시 (서비스 기본값 아님)
기간 1주, 기본 지급 50, 직업 소득 50, 고정비 30, 자유 예산 70, 저축 20, 상품 가격 140이면 자유 소비 예산 50. 상품을 살 수 있는 시기는 개별 기존잔액·소비 여부에 따라 달라진다. 수치는 테스트용이며 추천 화폐 가치가 아니다.

## C. 운영 정책 결정표
| 정책 | 기본 제안 | 이유 |
|---|---|---|
| 학생 간 송금 | OFF | 갈취/부당한 압력 및 인증 위험 |
| 학생 간 상품 거래 | OFF | 미성년자 거래 분쟁; 교사 감독형으로 추후 도입 |
| 직업 미배정 학생 | 기본 참여 소득 지급 | 수입 기회 공정성 |
| 공개 순위 | OFF | 낙인과 과잉경쟁 방지 |
| 급여 미수령/결석 | 교사 정책 별도 지정, 차별 검토 | 결석 사유 민감성 |
| 벌금 | OFF | 징벌적 학급관리 위험 |
| 청구서 | OFF | 기초 권리 침해 방지 |
| 저축 이자 | OFF, 수업 모듈로 활성화 | 부의 격차 가속 방지 |
| 마이너스 잔액 | OFF | 의도하지 않은 채무 방지 |
| 확률형 뽑기 | 제외 | 경제 학습 대비 위험 |
| 실제 가격 시세 연동 | 제외 | 투기·복잡성·데이터 불안정 |
| 교사 정정 | ON, 역거래 | 운영 신뢰성 |
| 학생 본인 정보 | 기본 비공개 | 개인정보 최소 수집 |

## D. 시뮬레이션과 불변 조건
- **모든 거래는 서버 측 검증 + 유일한 처리키**로 중복 방지.
- 계좌 간 이동은 돈이 늘지 않는다: 보통→저축은 같은 학생 내부에서 +와 -가 상쇄.
- 상품 결제는 재고와 금액의 상태를 한 번에 확정.
- 환불은 구매 취소와 연결되는 새 거래로 기록; 재고 복원 여부 정책 필요.
- 부분 일괄 지급 오류가 나면 누가 성공/실패했는지 정확히 보고하고, 성공분은 재실행 시 제외.
- 기간 변경/시간대(Asia/Seoul)/휴일 규칙의 적용 방식을 데이터 모델로 선언.

## E. 시뮬레이션으로 검증할 경제 사례
1. 25명 전체에 기본 소득을 주고 5명에게 직업 소득 추가 → 격차 추세를 교사만 확인.
2. 월 고정비를 소득의 80%로 설정 → 선택 여력이 부족하다는 경고가 나타나는지 확인.
3. 어떤 학생도 직업을 얻지 못한 경우 → 강제적 미납자 양산 방지.
4. 학생이 월급을 전부 쇼핑하면 → 목표 달성 시점이 어떻게 달라지는지 설명.
5. 세금/국고 기능 활성화 시 → 학생이 왜 세금을 내고 어떤 공공재에 쓰는지 이해 가능한 회고 수업 연결.

## F. 최소 교육적 사용성 기준
- 경제 단위인 화폐가 무엇을 뜻하는지 교사가 소개하는 첫 수업.
- 매주 학생이 '이번 주 선택 1개, 그 이유 1개, 다음 계획 1개'를 설명할 수 있게 함.
- 성취평가와 게임 화폐 잔액을 직접 연결하지 않음.
- 수학 계산 기능은 지도 목표에 따라 켜고 끌 수 있고 개인별 지원 제공.
