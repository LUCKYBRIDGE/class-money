# 제품 요구사항 초안

문서 상태: **설계 제안 (구현 전)** / 대상: 한국 초등학교, 교사 운영·학생 자율 참여 / 2026-11-08

## 목적
교실 활동을 화폐 보상 게임으로만 만들지 않고 학생이 **노동과 보상, 예산, 선택과 기회비용, 저축, 공동체 경제**를 직접 경험하는 안전한 모의경제 운영 도구.

## 사용자와 권한
- **교사(owner)**: 학급 관리, 경제규칙, 모든 원장 거래 승인·정정, 급여 일정, 학생 표시명, 내보내기.
- **학생(member)**: 자기 지갑·내역, 자신의 저축목표, 직업 신청, 상점 구매 요청. 다른 학생의 민감한 상세 잔액 조회 불가.
- **학급 보조 역할**: 은행원·상점관리자 등 교육 역할과 시스템 권한은 구별. 교사의 위임 없이 타 학생 계정 수정 불가.

## 사용 흐름
1. 교사: 반 만들기 → 화폐명/단위(정수 기본) → 학생 등록(이름 최소화, 번호·별칭) → 학급 직업 및 기본 급여 설정.
2. 학생: 간편 인증 → 내 지갑/거래내역 → 직업 신청·담당 활동 → 급여 획득 → 소비/저축 선택.
3. 교사: 오늘 할 일(승인함/지급 예정/이상 거래) 확인 → 지급·승인 → 학급 회고.
4. 확장: 모의 청구서·세금/공공서비스·저축이자·시장활동을 필요 시 열기.

## 화면/정보구조
- 교사 홈: **학생 · 지급/회수 · 직업/급여 · 상점 · 승인함 · 거래장부 · 경제설정 · 통계**.
- 학생 홈: **내 잔액 · 최근 내역 · 오늘의 직업 · 저축 목표 · 상점 · 알림**.
- 학급 대시보드: 전체 유통량/지급·회수 요약. 공개 개인별 자산 순위 OFF.
- 모바일/태블릿: 누르기 쉬운 큰 버튼, 가로스크롤 없는 핵심 흐름, 명확한 금액 단위.

## 기능 요구사항과 수용 기준
| ID | 기능 | 최소 수용 기준 |
|---|---|---|
| CM-01 | 학급 관리 | 한 교사가 여러 반 생성, 반별 설정/원장 격리 |
| CM-02 | 학생 등록 | 1~40명 이상 등록, CSV 입력 또는 붙여넣기, 중복 번호 검증 |
| CM-03 | 거래 원장 | 모든 지급/차감/구매/저축 이동은 고유 ID·시간·행위자·사유·금액 기록 |
| CM-04 | 교사 지급 | 개인·다중·모둠·전체 선택, 사유/금액 템플릿, 처리 결과 즉시 표시 |
| CM-05 | 오류 정정 | 정정 거래가 원거래 ID를 참조하며 감사 이력 남김 |
| CM-06 | 직업·급여 | 급여 주기/금액/유효기간 설정, 같은 지급기간 중복 지급 없음 |
| CM-07 | 상점 | 가격·재고/무제한·판매 활성 상태, 구매 요청→교사 승인/거절→잔액 반영 |
| CM-08 | 학생 지갑 | 사용 가능 잔액과 내역, 저축 분리(확장), 마지막 업데이트 표시 |
| CM-09 | 보안 | 학생은 본인 기록만 접근, 교사 계정의 해당 반만 변경 가능 |
| CM-10 | 데이터 이동 | CSV 내보내기, 학급 종료 전 백업/복원 정책, 학기 이관 정의 |
| CM-11 | 모바일/접근성 | 태블릿과 스마트폰, 키보드·스크린리더 대응, 색만으로 상태 구별하지 않음 |
| CM-12 | 학습 지원 | 계산 확인 모드는 선택적이며 학생별 접근성 예외 가능 |

## 핵심 정책(제안)
- **현금·실제 투자·실제 금융계좌 연동 금지**: 모의 교실 화폐만 사용.
- 학생의 기본 학습권·식사·좌석·휴식·안전·존엄성을 돈으로 사고팔지 않는다.
- 교사 재량 벌금은 기본 꺼짐; 비례·근거·이의제기 과정, 최대 차감액, 마이너스 잔액 정책 명시.
- 공개 랭킹·확률형 뽑기·실제 종목 투자 연동은 MVP 제외; 도입한다면 교육적·법적 재검토.
- 개인정보 최소화, 미성년자 보호자·학교 동의 및 국내 개인정보보호 규정 검토.
- 가격 변화 시 기존 승인된 주문은 주문 당시 금액을 기록.

## 경제 밸런스 제안
- 교사에게 주당 정기소득 A, 주당 필수지출 B, 보통 보상가격 C를 입력받아 예상 저축 소요주를 안내.
- A-B가 0 이하이면 경고. 한 학생의 직업 부재가 필수지출 미납으로 이어지지 않도록 기본소득 또는 지출 면제 옵션.
- 학급 공동 목표, 기부는 경쟁 대신 협력 활동으로 설계.

## 출시 단계
- **MVP**: CM-01~09 + 기본 거래 CSV + 학생 지갑/직업/상점.
- **V1**: 자동이체/저축 목표·이자(옵션), 예산 시각화, 수업 시나리오.
- **V2 후보**: 사회적 합의가 필요한 세금·공공예산·창업·교환시장·자산/대출.
- 각 단계는 **예정**일 뿐 구현·배포된 상태가 아님.
